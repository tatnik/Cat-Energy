# Учебный проект HTML Academy — сайт “Cat Energy”, лендинг для интернет-магазина кормов для кошек.

  -  Используется классическая вёрстка (HTML, CSS, SVG), мобильная и десктопная версия (адаптив).

  - Акцент на:

     - Кроссбраузерность (есть normalize.css)

     - Валидную семантику

     - Pixel-perfect для макета

     - Мобильную отзывчивую верстку

  - Папка source содержит исходный код (страницы, изображения, стили)

  - Есть демо-версия на GitHub Pages.

---

## В проекте реализовано:

  - Главная страница и страница каталога

  - Форма подбора программы питания для кота

  - Интерактивные элементы (меню, слайдер, кнопки)

  - Оптимизация графики (SVG, WebP), ретинизация, иконки через спрайты

  - Адаптивная сетка для разных разрешений

  - Стилизация стандартных форм, кастомные radio/checkbox

  - Использование SASS-препроцессора и современных CSS-фич (flexbox, @media)

  - Чистая структура проекта (разделение стилей, картинок, html)
